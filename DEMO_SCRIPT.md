# DEMO_SCRIPT.md — 3-Minute Grant Demo Recording Script

Record `make demo` end-to-end. Target length: 3 minutes. Audience: Konnex reviewers.

## Pre-recording checklist

- [ ] Clean checkout on `main` (or the commit you'll cite)
- [ ] `.env` present (copy from `.env.example`)
- [ ] No stale `fleet_dev.db` from a previous run (or accept it)
- [ ] Browser at 1920×1080, dark mode
- [ ] Terminal font size ≥ 14pt
- [ ] Screen recorder capturing both terminal + browser

## Recording steps

### 0:00–0:15 — One-command launch

**Terminal (full screen):**

```bash
make demo
```

**Narration:** "This is the Konnex Fleet Intelligence Subnet. One command boots the
backend, the headless simulator, and the dashboard. No Docker, no Gazebo, no
manual steps."

**Show:** The boot log lines:
- `Using Python: .venv/bin/python`
- `Backend healthy: http://127.0.0.1:8000`
- `Mission started: 5 robots / 20 tasks / seed 42 / policy=nearest`
- `Dashboard: http://127.0.0.1:3014`

### 0:15–0:45 — Dashboard overview

**Browser (http://localhost:3014):**

- Point at the 3D warehouse map: 5 robots moving, 20 task markers.
- Point at the left sidebar: robot states (idle/moving/delivering/charging/failed).
- Point at the right panel: live PoPW score, tasks 0/20 → climbing, collisions 0, energy ~100%.

**Narration:** "The dashboard streams real simulator state over WebSocket at 10 Hz.
Those robot positions are not animations — they're the orchestrator's ground truth."

### 0:45–1:15 — Live mission progress

**Show:** Tasks completing one by one. Robot paths drawing. Score updating.

**Narration:** "The fleet is running the `nearest` baseline policy. Watch the
PoPW score climb as tasks complete. Collisions stay at zero — the collision
monitor halts conflicting paths."

### 1:15–1:45 — Switch policy / benchmark table

**Browser:** Navigate to `/benchmarks` (or show the benchmark table panel).

**Show:** The real benchmark table:
- Hungarian: 99.8% success, 90.7 PoPW
- Cost Optimizer: 99.7%, 86.4
- Nearest: 99.5%, 85.8
- MAPPO (BC+DAgger): 100%, 92.9

**Narration:** "Three classical baselines plus a trained MAPPO actor. MAPPO beats
the best classical baseline by 2.2 PoPW points on 30 seeds, p=0.003."

### 1:45–2:15 — PoPW scoring + payments (Circle/Arc)

**Browser:** Navigate to the FleetPay Agent panel (if visible) OR show the
evaluation artifact.

**Show:** 
- The 6 PoPW components (mission_success 40%, safety 20%, efficiency 15%, energy 10%, coordination 10%, robustness 5%).
- The evaluation artifact JSON with SHA-256 hash.

**Narration (payments):** "The fleet is also an economic actor. The FleetPay
Agent turns decisions into policy-gated USDC payments settled on Arc. Mock mode
by default; the real Circle provider is implemented but needs credentials."

**Show:** `make payment-demo` terminal output (0xMOCK hashes) if recorded separately.

### 2:15–2:45 — Reproducibility proof

**Terminal:**

```bash
make verify-repro
```

**Show:** `[PASS]` lines, spread 0.0000, tolerance 0.5.

**Narration:** "Two independent validators reproduce the same score to 4 decimal
places. That's the reproducibility gate for the Spark tier."

### 2:45–3:00 — Close

**Show:** `experiments/results/` directory listing. `KONNEX_APPLICATION.md`.

**Narration:** "Every number in the README and the grant application comes from
a real run in `experiments/results/`, regenerated by script. Konnex adapter is
an honest STUB — SDK not publicly accessible. Gazebo wiring exists but live
execution is NOT RUN on this machine. Full status in STATE.md."

## Post-recording

- Upload video, paste URL into `KONNEX_APPLICATION.md` "Demo video" field and README.
- Update STATE.md with the video link.

## Known gaps to narrate honestly

- Gazebo live run: containerized; `gz` CLI not on host. `make sim` boots the container.
- Konnex real SDK: not publicly accessible; mock provider used.
- MAPPO PPO fine-tuning: negative result (documented in experiments/results/mappo_ppo_ft/).
